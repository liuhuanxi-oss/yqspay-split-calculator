# 首发介绍

有钱收开源了一款免费分账计算器：支持平台抽佣、固定货款、供应商分成与门店剩余金额分配，可试算三种手续费承担方式，并导出 JSON / CSV。

金额使用精确整数运算，尾差按明确规则分配，每次结果检查资金守恒。无需注册，规则在本地处理，MIT 开源。它是试算工具，不发起真实资金分账。

- 在线：https://liuhuanxi-oss.github.io/yqspay-split-calculator/
- 源码：https://github.com/liuhuanxi-oss/yqspay-split-calculator
- 有钱收：https://www.yqspay.com/smart-settlement
